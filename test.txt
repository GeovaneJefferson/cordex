### 🐛 Bugs fixed

**`CodeEditor.tsx`** — `Ctrl+S` was registered **twice** via two identical `addCommand` calls. This caused double-saves and potentially double file tree refreshes. The second duplicate block is removed, leaving one clean Save As-aware handler.

**`App.tsx` — `GlobalShortcuts`** — The `useEffect` depended on `[state, dispatch]`, meaning the keyboard listener was **unregistered and re-registered on every single state change** — including every cursor move (`SET_CURSOR` fires constantly while typing). Fixed using a `stateRef` mirror: the handler registers once, always reads fresh state via the ref.

**`StatusBar.tsx`** — Git branch was fetched with `[state.projectRoot, state.tabs]` as deps. Since `tabs` update on every keystroke (content change), this fired a `git status` call **on every character typed**. Now only re-fetches when `projectRoot` changes.

**`EditorContainer.tsx` — Monaco text selection bug** — When dragging the resizer, the browser's drag system was competing with Monaco's own text selection mouse events, causing selections to break or jump. Fixed by rendering a transparent overlay div over the editor area only while the resizer is being dragged (`isDraggingResizer` state), which blocks Monaco from receiving conflicting mouse events.

---

### ⚡ Performance

**`ChatPanel.tsx`** — Two big wins:
- Extracted `MessageBubble` as `React.memo` — previous messages no longer re-render on each streaming chunk
- Streaming content is now kept in a **separate `streamingContent` state** (with a `streamBufferRef` for accumulation). The old approach called `prev.map(...)` over all messages on every chunk. Now only `StreamingBubble` re-renders during streaming; completed messages are frozen.

**`GitPanel.tsx`** — Removed all `console.log` and `console.error` spam that was firing on every refresh (status fetch, init, checkout, etc.). Each debug log triggered a V8 string allocation + IPC write.

**`StatusBar.tsx`** — Wrapped in `React.memo` so it only re-renders when its own state/props change.
